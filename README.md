# 机器人学习论文笔记

**简体中文** | [English](README.en.md)

聚焦人形机器人学习的论文精读笔记，涵盖强化学习、动作重定向、全身控制、仿真到真机迁移，以及视觉–语言–动作（VLA）模型与世界模型。

## 在线演示

[![新版站点演示，包含学习路线图、arXiv 编号搜索、ACT 讲解与交互实验，以及笔记统计](media/site-demo.gif)](https://imchong.github.io/Robot_Learning_Paper_Notebooks/)

可以沿路线图阅读，也可以按论文标题或 arXiv 编号搜索。笔记详解方法、公式与实验结果，部分配有讲解动画、配音视频和交互实验。
