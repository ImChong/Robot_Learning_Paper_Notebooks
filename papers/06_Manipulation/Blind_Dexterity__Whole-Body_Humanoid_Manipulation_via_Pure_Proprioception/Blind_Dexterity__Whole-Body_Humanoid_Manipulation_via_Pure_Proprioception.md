# Blind Dexterity: Whole-Body Humanoid Manipulation via Pure Proprioception
**只用机身关节编码器（无相机 / 无 IMU / 无力矩传感器 / 无触觉），就在 Unitree G1 人形上学出全身灵巧操作：策略主动用「扫、拍、拖、滑」制造顺应性接触，让关节编码器随接触的变化本身变成一条「全身触觉通道」，物体位姿从而可从很短的本体感受历史里被解码出来**

## 🎯 一句话总结

人形操作通常堆一大堆外部传感器（多相机、IMU、力矩、触觉）才敢碰物体。本文反其道而行：**只留机身自带的关节编码器**，什么外部传感器都不用，却在 G1 上做出四件本来「看起来必须有视觉/触觉」的事——抗推的双足行走（连 IMU 都不用）、用脚主动接停足球、找到并拎起箱子把手、踩上随机摆放的滑板。作者的洞见是：当机器人以**顺应性（compliant）**方式主动接触环境时，**关节编码器读数随接触的演化本身就携带了物体状态信息**，等价于一条「全身触觉通道」。于是策略学会主动「扫、拍、拖、滑」去探测环境，物体位姿就能从**很短的一段本体感受历史**里被解码；再配一个与策略**分开训练**的任务专用状态估计器把这些信息读出来。结论：**关节编码器 + 顺应驱动**（如今商用机器人和低成本电机都已具备）已经是全身灵巧操作和交互式感知的一块相当强、且现成的基座，更丰富的传感可以在其上再叠加。

## ❓ 论文要解决什么问题？

- **传感器依赖太重**：人形做接触密集的操作，主流做法要靠视觉（相机遮挡/标定/噪声）、力矩或触觉传感器（贵、易损、装配复杂）。这些一旦缺失或失效，策略就废了。
- **一个被低估的信号**：机器人自己就有关节编码器。当它以顺应方式碰到物体，关节角的细微演化其实反映了接触力与物体位姿——但过去大多把它当噪声，任由「感知」隐式地寄希望于动作学习。
- **本文主张**：把这条隐式信号显式利用起来，仅凭本体感受也能完成需要「感知物体」的全身操作，并给交互式感知一个几乎零成本的落地基座。

## 🔧 方法拆解

### 1. 主动接触 = 制造可解码的信号
策略被鼓励产生**接触密集**的动作（扫/拍/拖/滑）。每一次顺应性接触都让关节编码器读数偏离「自由运动」时的轨迹，这个偏离量与物体的位置、朝向、是否被抓住强相关——相当于机器人用整个身体去「摸」。

### 2. 纯本体感受策略（仿真中从零 RL）
- 观测**只有**本体感受（关节位置/速度等）的短历史，**没有**相机、IMU、力矩、触觉。
- 在仿真里用强化学习从零训练，配合顺应性驱动与域随机化，训练完**零样本**迁移到真机 G1。
- 四个任务各训一个策略：抗推双足行走、用脚接停足球、寻找并拎起箱子、踩上随机位姿的滑板。

### 3. 分开训练的状态估计器
- 与策略**同步但完全独立**地训练任务专用状态估计器：输入同一段本体感受历史，输出物体状态（如位姿）。
- 关键现象：**信息量大的接触发生后，估计误差迅速下降**——直接印证「编码器随接触的演化确实携带物体信息」，也说明策略是在主动「问」出状态。

## 💡 核心贡献

1. **重新定义「本体感受」的价值**：指出关节编码器在顺应性接触下形成的「全身触觉通道」，是被长期低估的、可用于操作的感知信号。
2. **纯本体感受全身操作**：在真机 G1 上，仅凭编码器完成四类看似「必须有视觉/触觉」的任务，包括**不用 IMU** 的抗推双足行走。
3. **交互式感知的实证**：用与策略分开训练的状态估计器证明——主动接触后物体状态的可解码性显著提升，把「感知靠动作」量化了出来。
4. **可落地的基座**：顺应驱动 + 关节编码器已在商用机器人与低成本电机上普遍具备，为「先能用、再叠加更丰富传感」提供了极低成本的起点。

## 📊 关键结果

| 任务 | 传感条件 | 结果 |
|---|---|---|
| 抗推双足行走 | 仅编码器，**无 IMU** | 受推后仍能稳定行走 |
| 用脚接停足球 | 仅编码器 | 主动触球并停住 |
| 寻找并拎起箱子 | 仅编码器 | 靠把手把箱子拎起 |
| 踩上随机位姿滑板 | 仅编码器 | 找到并踩上滑板 |

- **共性证据**：各任务的状态估计误差都在「信息量大的接触」之后快速下降，支撑「编码器=隐式触觉」的核心论点。
- 全部策略在仿真中从零训练、**零样本**迁移真机 G1。

## 🤖 对人形机器人领域的意义

| 方向 | 含义 |
|---|---|
| **降本 / 鲁棒** | 少一层对相机/触觉的依赖，就少一处标定、遮挡与硬件故障点，利于真机长时可靠运行 |
| **交互式感知** | 给「用动作换感知」提供了在真人形上的落地样例，可作为视觉/触觉缺失时的兜底通道 |
| **传感融合起点** | 把纯本体感受当基座，再叠加视觉、触觉，是一条「渐进增强」的工程路线 |
| **顺应控制价值** | 强调顺应性驱动不仅让接触安全，还「顺带」产生了可用于感知的信号 |

## 🎤 面试参考

**Q：只有关节编码器，凭什么能「感知」到物体？**
A：关键在顺应性接触。机器人以可让步的方式主动碰物体时，关节角会偏离自由运动时的轨迹，这个偏离量与接触力、物体位姿强相关。把一段本体感受历史喂给状态估计器，就能把物体状态解码出来——编码器于是成了一条「全身触觉通道」。

**Q：为什么状态估计器要和策略分开训练？**
A：为了干净地验证「本体感受里到底有没有物体信息」。估计器不参与决定动作，只负责从同一段观测里读状态；一旦看到「信息量大的接触之后估计误差骤降」，就说明是策略主动探测带来了可解码信号，而不是网络记住了任务捷径。

**Q：连行走都不用 IMU，会不会不稳？**
A：论文的抗推行走正是用来证明纯编码器足够：受到外推时，关节编码器的响应本身携带了扰动信息，策略据此调整，展示了在没有惯性测量的情况下仍能维持平衡的能力。

**Q：这套方法的边界在哪？**
A：它是「够用且极省」的基座，而非要取代视觉/触觉。远距离目标定位、精细纹理识别等仍需外部感知；本文的定位是：先用零成本的本体感受把接触密集操作做起来，再在其上叠加更丰富的传感。
