# A Dual-Cam Parallel Elastic Actuator with Shared Gas-Spring Compensation for Humanoid Ankles
**双凸轮 + 单气弹簧：让一根弹性元件同时替人形踝的俯仰(pitch)和翻滚(roll)两个自由度分担静态力矩，把电机从「长期扛着重力」里解放出来，又不占用踝部本就紧张的空间。**

## ❓ 这篇论文要解决什么问题？

人形踝关节被两个相互冲突的需求夹住：

- **要大力矩**：一个 65 kg 人形，踝在支撑相需要约 **127 N·m（俯仰）/ 70 N·m（翻滚）** 的力矩；
- **要能效与动态性能**：用**大减速比齿轮箱**能凑出力矩，但传动损耗和反射惯量都上升，牺牲动态响应；换**低减速比 + 高扭矩密度电机（QDD 路线）**动态好了，可**静态站立/负重时电机要持续吃大电流**，发热与续航都吃不消。

而踝关节本身是**在狭小空间里做球面运动、力矩需求还高**的部位。所以问题变成：**能不能让弹性元件在静态时替电机扛住那份「重力/姿态保持」力矩，且不额外占用踝部空间？**——这正是并联弹性驱动器（PEA）的思路，但踝有俯仰、翻滚两个自由度，若每个自由度各配一套弹簧，体积与质量都难以塞进踝部。

## 🦴 机构设计要点：双凸轮 + 共享气弹簧

核心创新是 **一根气弹簧、两个凸轮、共同补偿两自由度**：

| 子系统 | 做法 | 目的 |
|---|---|---|
| **双偏心凸轮** | 俯仰、翻滚各配一个偏心凸轮，凸轮通过滚子(roller)接触**同一根气弹簧** | 一根弹簧服务两个自由度，省掉「每轴一套弹性元件」的体积/质量 |
| **共享气弹簧** | 踝在俯仰或翻滚方向转动时，对应滚子沿凸轮型线滚动、压缩气弹簧 | 弹簧力经「接触法线到转动极点」的力臂产生补偿力矩 |
| **滚子接触** | HK0609FM 滚针轴承（φ10 mm）做滚子，减小接触摩擦 | 让凸轮-弹簧之间近似纯滚动传力 |
| **电机 + 滚珠丝杠** | F50-13 电机（额定 1.27 N·m）+ 滚珠丝杠传动做主驱动 | PEA 只补偿静态力矩，动态跟踪仍由电机负责 |
| **紧凑集成** | 整条小腿模型 495 mm 高、3.56 kg，凸轮用 7075-T6 铝 | 在踝部狭小空间内落地 |

> 📌 核心取舍：**用「共享单弹簧 + 精心设计的凸轮型线」换取紧凑度**——代价是两自由度通过同一根弹簧发生**耦合**（一个方向的压缩会影响另一个方向可用的补偿），这也成为本文最大的性能软肋（见下）。

## 🧮 耦合数学模型与凸轮型线优化

因为两个凸轮压的是**同一根**气弹簧，弹簧力是两个自由度压缩量之和的函数：

$$F_s(\theta_1,\theta_2) = F_{si} + k\big(\Delta c_1(\theta_1) + \Delta c_2(\theta_2) + c_p\big)$$

其中 $\theta_1$ 为俯仰、$\theta_2$ 为翻滚，$\Delta c_i$ 是各自凸轮引起的压缩量。于是两个方向的输出力矩变成**耦合的二元函数**。

**优化框架**：把凸轮半径型线 $R(\theta)$ 参数化为 **4 阶多项式**，以「生成力矩逼近参考力矩的平方误差最小」为目标，约束包括气弹簧行程上限、以及**曲率约束（滚子半径不得超过凸轮曲率半径，保证滚子始终能贴合）**。用 **CasADi + IPOPT** 求解该约束优化，并带**选型反馈回路**（验证选定的弹簧/轴承等标准件是否可行）。

## 🔬 设计与验证流程

1. **CAD 集成（CREO）**：完整下肢模型 495 mm / 3.56 kg，含 F50-13 电机、滚珠丝杠、φ10 mm HK0609FM 滚针轴承、气弹簧（GSU70-7-YW 或 MGSN16-10）。
2. **有限元（FEA）**：对 7075-T6 铝凸轮在峰值载荷下做静力分析，**次表面 von Mises 应力约 500 MPa**（接近屈服），但判定为局部 Hertzian 接触应力、单次加载下无宏观疲劳，故可接受。
3. **运动学仿真**：用三组参考力矩验证补偿效果——① 解耦正弦、② 耦合混合三角函数、③ 4 kg 负载平衡姿态。

## 📊 实验结果速览

| 气弹簧 | 参考力矩 | R²（俯仰/翻滚） | 平均力矩下降 | 峰值力矩下降 |
|---|---|---|---|---|
| GSU70-7-YW | 解耦 | 0.99 / 0.99 | 79.0% / 58.7% | 81.0% / 64.6% |
| MGSN16-10 | 解耦 | 0.99 / 0.99 | **97.7% / 95.3%** | 95.2% / 90.3% |
| MGSN16-10 | 4 kg 负载 | 0.99 / 0.96 | 96.0% / 81.9% | 91.9% / **65.6%** |

- **解耦场景**下补偿极好（R²≈0.99，力矩最高可卸掉 ~97%）；
- **耦合场景**因两自由度共享弹簧而退化（R²：俯仰 0.87–0.94、翻滚 0.67–0.92）；
- 负载下翻滚峰值仍能减 **65.6%**，代表对电机相当可观的「减负」。

| 方向 | 含义 |
|---|---|
| **踝关节驱动** | 给出「一根弹簧补偿双自由度」的紧凑 PEA 方案，缓解踝部空间/质量约束下的静态力矩难题 |
| **能效** | 静态/负重时把重力力矩交给弹簧，电机电流与发热大幅下降，利于续航与热管理 |
| **设计方法学** | 从任务力矩需求→凸轮型线的优化框架（4 阶多项式 + 行程/曲率约束 + IPOPT）可迁移到其他并联弹性关节 |
| **硬件-控制协同** | 把「静态承重」做进机构，等于在硬件层先替控制/电机减负 |

## ⚠️ 局限

- **耦合效应**：解耦拟合 R²≈0.99，但耦合场景掉到俯仰 0.87–0.94、翻滚 0.67–0.92——单弹簧共享是紧凑度的代价，也是补偿精度的天花板；
- **仅单一载荷 FEA**：只做了峰值静载分析，未做循环疲劳；
- **尚无样机**：所有结果均为仿真，物理实验留待后续；
- **多项式阶数**：4 阶多项式对正弦类参考够用，复杂轨迹可能需要更高阶。

## 🎤 面试参考

**Q：并联弹性驱动器（PEA）解决什么问题？为什么用在踝？**
A：PEA 把一个弹性元件与电机**并联**，专门分担**静态/重力力矩**，让电机在站立、负重时不必持续吃大电流（省电、降温）。踝关节在支撑相要扛很大的重力力矩、空间又小，是 PEA 收益最明显的位置之一。

**Q：这篇的「双凸轮 + 共享气弹簧」新在哪？**
A：踝有俯仰、翻滚两个自由度，常规做法是每个自由度各配一套弹簧，体积质量塞不进踝。本文用**两个偏心凸轮压同一根气弹簧**，一根弹簧同时补偿两个方向，靠凸轮型线把「转角→压缩→补偿力矩」的映射设计成想要的形状。

**Q：为什么耦合场景性能会掉？**
A：因为两个凸轮压的是同一根弹簧，弹簧力是两方向压缩量之**和**。当俯仰、翻滚同时大幅偏转时，一个方向占用了弹簧行程，另一个方向可用的补偿就被「抢走」，导致两方向力矩相互牵制、拟合 R² 下降。这是「共享单弹簧换紧凑」的固有代价。

**Q：凸轮型线是怎么定出来的？**
A：把凸轮半径型线参数化为 4 阶多项式，以「生成力矩逼近目标力矩的平方误差最小」为目标，约束气弹簧行程和曲率（滚子半径 ≤ 凸轮曲率半径，保证贴合），再用 CasADi+IPOPT 求解，并带标准件选型的反馈校验。
