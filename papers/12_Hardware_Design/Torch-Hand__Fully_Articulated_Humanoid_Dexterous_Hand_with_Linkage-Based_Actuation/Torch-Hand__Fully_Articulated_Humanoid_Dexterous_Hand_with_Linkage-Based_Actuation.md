# A fully articulated humanoid dexterous hand with human-level joint structure enabled by linkage-based actuation
**Torch-Hand 照人手的关节层级做出 21 个关节（拇指 5、其余四指各 4），16 台电机全部放在手掌里，每台电机经「丝杠 → 滑块 → 曲柄滑块连杆」只管一个关节；远端两节靠一根可压缩的连杆在空载时跟着中节联动、碰到物体时自动解耦。丝杠自锁让它单指指尖力 60 N 以上、能提起 40 kg 哑铃，重复定位误差在 ±0.031 mm 以内**

## ❓ 这篇论文要解决什么问题？

作者把灵巧手设计概括成一个「**灵巧 — 精度 — 负载**」的三难：

| 路线 | 优点 | 问题 |
|---|---|---|
| 电机 + 齿轮放在手指里（DLR-HIT） | 关节运动确定 | 手指粗重、背隙、发热，难以塞进很多自由度、也扛不了持续负载 |
| 气动软手 | 柔顺、安全 | 刚度低、变形耦合，精度和持续出力都差 |
| 腱绳（含刚柔混合） | 远端轻、自由度多 | 摩擦、绳的弹性、松弛和疲劳让力 / 位置控制不可重复 |
| 混合驱动 | 功能多 | 接口多，带来柔顺、标定漂移和新的故障点 |
| 已有连杆手 | 刚、传力效率高 | 要么运动学强耦合，要么偏离人手形态；ILDA 手（15 个主动自由度、指尖 34 N）拇指是固定的，并联式结构让控制变复杂 |

Torch-Hand 的思路：**全部用刚性连杆传动、电机全放手掌，但把结构排成串联机械臂那样——一台电机对应一个关节**。

## 🦴 设计：每个关节一条独立的传动链

### 一条传动链长什么样

电机转角 $\psi_i$ → 丝杠把转动变成滑块的直线位移 $s_i$ → 曲柄滑块连杆把位移变成关节转角 $\theta_i$：

$$s_i = \frac{p_i}{2\pi}\,\psi_i, \qquad \theta_i = f_i(s_i)$$

$p_i$ 是丝杠导程，$f_i$ 是由连杆几何闭合关系决定的单输入单输出函数（补充材料式 S1–S27）。因为每条链只管自己的关节，得到的关节向量直接代进 DH 模型就能算指尖位姿，不用解全局耦合的逆解。

### 四根手指：4 个关节、3 台电机

- MCP 侧摆、MCP 屈伸、PIP 屈伸各一个曲柄滑块单元，各自独立；
- MCP 屈伸用**空间四杆**，驱动杆两端是球头杆端轴承，适应关节朝向的变化；
- PIP 的动力经一个**万向节**传过去，万向节中心对准 MCP 两根轴的交点，所以 PIP 的传动不干扰 MCP 的两种运动（装配时专门对准这一点）；
- **DIP 不单独配电机**：由一个四杆机构接在 PIP 传动上，和 PIP 按人手的规律一起弯。

### 可压缩连杆：空载联动、受力解耦

DIP 四杆里有一根**可压缩连杆**：

- 空载时它保持原长，DIP 跟着 PIP 联动，像真人手指那样两节一起弯；
- PIP 被物体挡住、或 DIP 单独受力时，PIP 和 DIP 共用的那根杆停住，DIP 机构变成等效的曲柄滑块，可压缩杆充当滑块，DIP 可以自己转。

这样既保留了自然的指间协调，又能在抓物体时让末节贴合。拇指的 MCP–IP 用同样的设计。

### 拇指：5 个关节、4 台电机

CMC 处放了**三根互相垂直的转轴**（旋转、侧摆、屈伸），再串上 MCP 屈伸和 IP 屈伸。三轴正交让拇指的朝向可以拆成三个独立分量，对掌范围大、几乎没有寄生耦合。

### 数一下

| | 关节 | 电机 |
|---|---|---|
| 四指 × 4 | MCP 侧摆、MCP 屈伸、PIP、DIP（被动联动） | 3 × 4 = 12 |
| 拇指 | CMC 旋转、CMC 侧摆、CMC 屈伸、MCP、IP（被动联动） | 4 |
| 合计 | **21** | **16** |

## 🚶 具体实例：一圈电机转角能让滑块走多远

论文没有给出丝杠导程的具体值，下面取 $p = 1$ mm 只为说明式 (3) 的量级（**这是我们的假设**）：

| 电机转角 $\psi$ | 滑块位移 $s = \dfrac{p}{2\pi}\psi$ |
|---|---|
| $2\pi$（一整圈） | 1 mm |
| $\pi/2$（四分之一圈） | 0.25 mm |
| 1°（$\approx 0.01745$ rad） | $\approx 0.0028$ mm |

电机转 1° 滑块只走约 3 µm，这就是丝杠带来的「大减速比」：同样的电机扭矩换来大得多的推力，滑块的定位分辨率也很细。论文测得的重复定位误差平均约 0.011 mm、最大 ±0.031 mm，和这个量级是吻合的；而滑块反推电机时要克服丝杠的摩擦角，梯形丝杠导程小时就**自锁**，这是能提 40 kg 而不用持续通电的原因。

### 任务：3 × 3 矩阵

横轴是操作难度（指尖精细操作 → 物体操作 → 用工具出力），纵轴是交互负载。九个任务：尼龙线（0.35 mm）穿 0.5 mm 针眼、开口红盖并拧出口红、拧开拧紧的瓶盖、移液枪稀释并控制液滴、拿碳酸钙做制取二氧化碳的实验、剪线并插进分线器、拧螺丝、握电钻打孔、羊角锤从木板上拔钉。左右手两个版本装在 UR5 上，机械臂位姿事先遥操作录好再回放；手的动作来自数据手套（20 Hz），先重建人手指尖轨迹、换到 Torch-Hand 手掌坐标系，再逐指解逆运动学，按 20 Hz 下发。

## 🤖 对人形机器人领域的意义

| 方向 | 含义 |
|---|---|
| 控制 | 电机 ↔ 关节一一对应、关节 ↔ 指尖是串联链，学习型策略和遥操作重定向可以直接在关节空间里工作，不用补偿耦合 |
| 负载 | 连杆 + 丝杠自锁让灵巧手第一次在「21 个关节」的同时有 40 kg 级的负载，人形用手干重活（工具、搬运）多了一个硬件选项 |
| 远端轻 | 电机全在手掌，手指里只有连杆，惯量小、也留出了装触觉的空间 |
| 被动联动 | 可压缩连杆是一个省电机的小技巧：空载像人一样联动、接触后自适应，省了 5 台电机 |

## ⚠️ 局限

- **没有学习或闭环控制实验**：所有演示都是数据手套 / 预录轨迹回放，没有触觉和力反馈，作者把视觉、触觉和学习型控制列为下一步；
- **没测速度和耐久**：论文没报关节速度、带宽，也没做长时间疲劳、动态工具使用下的可靠性测试（作者自己在讨论里提到要补）；
- **丝杠自锁不可反驱**：手被动顺从外力的能力弱，和 PHD-Hand、MIDAS 这类强调可反驱 / 低阻抗的手是相反的取舍（论文没讨论这点，这是我们的看法）；
- **尺寸和重量**：手长 235 mm、手指 137.5 mm，比真人略大；论文没给整手质量和成本；
- **未开源**：没有 CAD、代码，也没公开补充视频；
- 小问题：补充材料表 S6 表头把重复定位误差的单位写成了 N（按正文应为 mm）；正文写食指协同指尖力 60.72 N，表 S7 对应行最大是 61.72 N。

## 🎤 面试参考

**Q：21 个关节为什么只要 16 台电机？**
A：四指的 DIP 和拇指的 IP 不单独驱动，各由一个四杆机构接在上一节（PIP / 拇指 MCP）的传动上联动，5 个关节省掉 5 台电机。联动杆里有一根可压缩连杆：空载时保持原长、两节一起弯；接触受力时被压缩，末节可以自己转，相当于在接触时自动解耦。

**Q：为什么说它「像串联机械臂」？好处是什么？**
A：每个主动关节有自己的一条「电机 → 丝杠 → 滑块 → 曲柄滑块」链，单输入单输出，关节角只由自己的电机决定；整根手指再按 DH 参数串起来算指尖位姿。所以正逆运动学都简单，不用像并联或腱绳手那样补偿关节之间的串扰。

**Q：丝杠带来了什么，又牺牲了什么？**
A：带来大减速比（增力、定位分辨率细，重复定位 ±0.03 mm 内）和自锁（提 40 kg 哑铃不用持续出力）。代价是不能反驱、被动柔顺差，速度一般也受限，接触时的柔顺只能靠控制或额外的机构（比如那根可压缩连杆）。
