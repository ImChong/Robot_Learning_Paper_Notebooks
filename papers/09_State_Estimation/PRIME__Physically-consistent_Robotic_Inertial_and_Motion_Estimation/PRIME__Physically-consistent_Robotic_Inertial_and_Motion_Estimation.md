## 🎯 一句话总结

主流状态估计（EKF / 动捕）只能恢复**运动学**——关节角、机身位姿、速度，却把**接触力、接触时序、惯性参数**统统留成未知量，导致在富接触动作里重建出的轨迹**违反刚体动力学**（力不闭合、脚看着在地上却没有支撑力）。PRIME 把这件事写成一个 **MAP（最大后验）/ 参数化全信息估计（PFIE）** 问题：以测得的运动学 + 关节力矩为观测，一次性联合优化出**动力学一致的状态轨迹 (q, v)、摩擦接触冲量 λ、以及物理合理的惯性参数 θ（每连杆质量 / 质心 / 6 个惯量分量）**。核心工具是**可微接触动力学**——用对数障碍把带摩擦锥的二阶锥规划（SOCP）松弛成无约束凸优化，再借隐函数定理拿到接触冲量对状态的**解析梯度**，从而能塞进 **FDDP（可行性驱动的微分动态规划）** 求解器里端到端优化。产物是「**带接触力与接触标注的物理一致运动重建**」，可作为大规模行为建模 / 机器人基础模型的高质量训练数据。

## ❓ 论文要解决什么问题？

给机器人做状态估计时，常见做法有两条，都只拿到「半张图」：

1. **EKF / 滤波**：融合 IMU + 运动学，估出机身位姿与速度——但**看不到接触力，也不知道真实惯性**（负载变了、质心偏了都察觉不到）。
2. **动作捕捉 / 视觉**：能把关节轨迹拍得很准，但同样只有**运动学**，没有力。

后果是：在跳跃、落地、支撑切换这类**富接触**动作里，重建出来的轨迹**不满足刚体动力学**——牛顿-欧拉方程不闭合、脚明明贴地却没有对应支撑力、机身加速度和实际受力对不上。这样的数据拿去训练策略 / 世界模型 / 基础模型，就是在喂「物理上不可能」的样本。

PRIME 的目标：**不加任何力传感器**，只用已有的运动学测量 + 关节力矩指令，把日志**重建成物理一致、且带接触力与惯性标注**的轨迹。

## 🔧 方法拆解

### 1. 把估计写成一个 MAP / PFIE 问题

优化目标是三项加权二次代价之和：

- **参数先验项** ‖θ − θ̂‖²：让辨识出的惯性参数别离出厂标称值太远；
- **过程噪声项** Σ‖δ_x‖²：惩罚状态轨迹违反动力学的程度（浮动基座权重更高）；
- **测量噪声项** Σ‖δ_y‖²：让重建轨迹贴近实际测到的运动学。

联合优化变量 = **状态轨迹 (q, v) + 接触冲量 λ + 惯性参数 θ**。

### 2. 观测用什么（不用力传感器）

- **关节力矩 u**：从电机 / 力矩传感读得，作为已知输入；
- **关节位置 / 速度 α, α̇**；
- **浮动基座位姿 p, R**（动捕）、基座线速度 v（动捕差分）、角速度 ω（IMU）。
- **不需要**任何接触力 / 接触时序传感器——这些都是被反解出来的。

### 3. 可微接触动力学（全文关键）

- 用 **Anitescu 摩擦模型**表达接触约束：非穿透互补 φ(q⁺) ≥ 0 ⊥ λⁿ ≥ 0，切向落在摩擦锥内 ‖λᵗ‖ ≤ μλⁿ；
- 用**对数障碍松弛**把带锥约束的 SOCP 变成**无约束凸优化**，平滑参数 κ 在「刚性」与「数值可解」之间折中；
- 接触冲量由定制 **Newton 求解器**（可行性投影 warm-start）解出，再借**隐函数定理**做灵敏度分析，拿到 λ 对状态的**解析梯度**——这一步让接触过程能直接接进基于梯度的轨迹优化。

### 4. 求解器

- 外层用 **FDDP**（可行性驱动的多重打靶 DDP），能容忍初始化时的动力学违背；
- 工程实现：C++ + **Pinocchio**（动力学导数）+ **Crocoddyl**（DDP）。

### 5. 脚底四点接触模型

用「脚四角」四点接触重建**平面足**的接触分布，无需专用足底传感器，直接和 Bertec 测力板（±0.4 N、1000 Hz）对比验证。

## 💡 核心贡献

1. **物理一致的联合估计**：一次 MAP 优化同时给出「动力学一致轨迹 + 接触力 + 惯性参数」，而不是只估运动学，从根上消除「脚贴地却无支撑力」这类矛盾。
2. **可微接触动力学**：用 Anitescu 摩擦 + 对数障碍松弛把接触过程变成可求梯度的凸子问题，让接触能端到端进轨迹优化——这是把 SOCP/LCP 塞进 DDP 的关键工程点。
3. **无力传感器辨识惯性**：只靠力矩 + 运动学就能把负载 / 质心偏移辨识出来（Go2 加 4.6 kg 负载、G1 加约 2.9 kg 都能估准）。
4. **面向数据基础设施**：产物是「力与接触标注」的真机运动重建，定位为给大规模行为建模 / 机器人基础模型供数据的底层工具。

## ⚠️ 局限

- **虚假离地（spurious lift-off）**：Anitescu 松弛在切向滑动时可能出现非物理的法向分离——但对运动中「硬、短时」的接触可接受；
- **人形手指未建模**：G1 的三指手没进模型，导致上肢关节力矩失配；
- **无形式化可观测 / 可辨识性分析**；
- **平滑参数 κ 靠经验选取**，其影响放在附录里做敏感性分析。

## 🎤 面试参考

**Q：PRIME 和普通 EKF 状态估计差在哪？**
A：EKF 只融合运动学、输出位姿/速度，看不见力也不知道真实惯性；PRIME 把它写成一次带物理约束的 MAP 轨迹优化，**同时**反解接触力和惯性参数，强制整条轨迹满足刚体动力学。代价是它是**批处理 / 离线**（Go2 一段要约 200 s 收敛），EKF 则是实时递推。

**Q：不装力传感器，怎么可能估出接触力？**
A：靠「力矩 + 运动学 + 动力学模型」闭环。已知关节力矩和机身运动，牛顿-欧拉方程里唯一未知的就是外部接触力；把接触写成可微的摩擦锥约束后，优化器会解出「让动力学最自洽」的那组接触冲量。惯性参数不准会破坏这个自洽，所以它顺带被一起辨识出来。

**Q：为什么要把接触做成「可微」？**
A：因为要用基于梯度的 DDP 端到端优化。硬接触（LCP/SOCP）本身不可微、带互补/锥约束；用 Anitescu 摩擦 + 对数障碍松弛成无约束凸问题后，再借隐函数定理拿到接触冲量对状态的解析梯度，接触过程才能塞进轨迹优化的反向传播里。

**Q：这套东西最大的价值是什么？**
A：不是又一个滤波器，而是一台「**数据清洗机**」——把真机采到的、只带运动学的原始日志，重建成力与接触一致的物理轨迹。这类高保真、带力标注的数据正是训练机器人基础模型 / VLA 最稀缺的燃料。
