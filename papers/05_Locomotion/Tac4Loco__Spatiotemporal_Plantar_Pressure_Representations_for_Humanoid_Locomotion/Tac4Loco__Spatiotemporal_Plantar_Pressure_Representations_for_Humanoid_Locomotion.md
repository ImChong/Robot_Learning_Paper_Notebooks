## 🎯 一句话总结

人形在斜面 / 台阶边缘 / 泡沫等复杂地形上容易「踩不实」而摔倒。Tac4Loco 把**多阵列足底压力**当作**直接反馈**接进 RL 策略：用**保拓扑的序数表示**对齐仿真与真机压力信号，再用**空间 + 时间双分支编码器**提取足底压力的时空特征，和本体感知一起喂给**非对称 actor-critic** 策略——在倾斜、部分、非对称、动态变化的支撑面上都拿到更好的跟踪与支撑适应，并**零样本泛化**到泡沫、碎石等未见柔顺/非结构地面。

## ❓ 论文要解决什么问题？

现有人形行走策略主要依赖**本体感知**（IMU + 关节状态）或**外感知**（高度图 / 深度）。但脚和地面「到底怎么接触的」这条最关键的信息，往往只能**间接推断**：

1. **踩不实的地形**——斜面、台阶边缘、只有半只脚着地的部分支撑、左右脚受力差异极大的非对称支撑，仅凭本体感知很难及时发现「支撑正在丢失」。
2. **柔顺 / 非结构地面**——泡沫、碎石这类地面的力学响应仿真里很难建准，纯几何感知也看不出「软」。
3. **仿真-真机的信号鸿沟**——就算在仿真里给脚加了接触力，真机 FSR 鞋垫的读数分布、噪声、标定都与仿真差很多，**直接把原始压力值喂进策略会 sim-to-real 崩掉**。

Tac4Loco 的思路是：**把足底压力升格为一等反馈信号**，并用「序数表示 + 时空双分支编码」把它变成一段既能跨域对齐、又富含时空结构的紧凑特征。

## 🔧 方法拆解

### 1. 观测空间（可部署部分）

- **本体感知**：IMU、关节位置/速度、步态相位、指令速度。
- **序数足底压力图**：每脚 60 阵元 FSR，经**非均匀分箱**量化为 **31 个有序等级**——只保留「相对压力大小的秩序」，从而对齐仿真与真机（真机绝对标定不必精确）。
- **时序压力-本体历史**：8 个数据包的序列，**近端密集 + 远端稀疏**采样，兼顾即时反应与趋势判断。
- **接触条件下的地形朝向**：由压力反推的前后 / 内外方向鞋底倾角，附带**支撑置信度**。

### 2. 双分支足底压力编码器

- **空间分支**：CNN tokenizer 把序数压力图转成 token，加空间位置嵌入，再用**多头交叉注意力**、以增广后的本体状态为条件，抽取「此刻脚下压力分布」的空间特征。
- **时间分支**：对 8 包历史做 **1D 时间卷积**，用「最新特征 + 时间均值 + 最新↔最早差分」三路汇总，经 MLP 融合，抽取「支撑随时间怎么变」的动态特征。
- 两支特征与增广本体感知拼接，作为**非对称 actor-critic** 的 actor 输入。

### 3. 训练设置与奖励

- **仿真**：MuJoCo / **mjlab** GPU 并行环境，每脚在 taxel 位置布 **60 个接触球**以生成压力监督。
- **算法**：PPO + **地形课程**；**50 Hz** 策略输出、**200 Hz** 底层 PD。
- **奖励四组**：① 任务跟踪（速度指令）；② 运动正则（抑制躯干倾斜/角速度/姿态偏离/关节越界）；③ 步态塑形（周期落足、摆动抬高、惩罚打滑与硬着地）；④ **足底支撑对齐**（鼓励脚与地面贴合接触）。

## 💡 核心贡献

1. **把足底压力当直接反馈**：不再从本体感知「间接猜接触」，而是把多阵列足底压力显式接进策略，让「脚下踩得实不实」成为一等观测。
2. **保拓扑序数表示**：用非均匀分箱把压力量化为有序等级，只保留相对大小秩序，跨越仿真-真机的标定 / 噪声鸿沟，是 sim-to-real 能成的关键。
3. **时空双分支编码器**：空间分支（CNN + 交叉注意力）看「此刻压力分布」、时间分支（1D 卷积）看「支撑的动态变化」，两者互补。
4. **复杂支撑鲁棒 + 零样本泛化**：对倾斜 / 部分 / 非对称 / 动态支撑显著更稳，并零样本迁移到泡沫、碎石等未见柔顺 / 非结构地面。

## 📊 关键结果

| 场景 | 基线（仅本体） | Tac4Loco |
|---|---|---|
| 仿真 · 斜面 (15–20°) 存活率 | 22.0% | **77.9%** |
| 仿真 · 随机支撑高度 存活率 | 71.7% | **96.5%** |
| 仿真 · 平坦/缓起伏 线速度误差 | 0.337 m/s | **0.131 m/s** |
| 真机 · 9° 斜坡边缘（部分支撑） | 7/10 | **10/10** |
| 真机 · 侧向 9° 上坡（非对称支撑） | 1/10 | **8/10** |
| 真机 · 15° 上 + 9° 下 坡面切换 | 0/10 | **10/10** |
| 真机 · 泡沫平台（零样本柔顺） | 0/10 | **7/10** |

**消融**：去掉压力编码器，V 形沟槽存活率 100%→68.8%；去掉地形估计，斜面存活率 77.9%→42.2%——两条支路都关键。

## 🤖 对人形机器人领域的意义

| 方向 | 含义 |
|---|---|
| **感知补全** | 在「本体 + 视觉/高度图」之外补上「触觉/足感」这条被长期忽视的通道，尤其对看不出软硬、看不清边缘的地形 |
| **Sim-to-Real 方法论** | 序数表示给「难标定的触觉传感器」提供了一条通用的跨域对齐范式，可推广到手部触觉等场景 |
| **鲁棒行走** | 部分 / 非对称支撑是真实楼梯、门槛、斜坡边缘的常态，触觉反馈直接提升这些高频跌倒场景的成功率 |
| **柔顺地面** | 泡沫 / 碎石等仿真难建模的地面，靠「实测压力」而非「预测几何」来适应，泛化性更好 |

## 🎤 面试参考

**Q：为什么不直接把原始 FSR 压力值喂给策略，而要做序数量化？**
A：真机 FSR 的绝对读数受标定、温漂、鞋垫贴合影响很大，和仿真里的接触力分布对不齐，原始值直接进策略几乎必然 sim-to-real 崩。序数表示只保留「哪块压力更大」的**相对秩序**，用非均匀分箱映射到固定等级，仿真和真机在「秩序」层面一致，从而稳定迁移。

**Q：空间分支和时间分支各解决什么？**
A：空间分支（CNN token + 以本体为条件的交叉注意力）刻画「此刻脚下压力怎么分布」——是踩在边缘、只有前掌着地还是整脚贴合；时间分支（8 包历史 1D 卷积，取最新/均值/差分）刻画「支撑正在怎么变化」——是正在失去接触还是重新压实。消融显示两条都掉性能。

**Q：非对称 actor-critic 在这里的作用？**
A：critic 训练时能用接触真值、地形几何等**特权信息**把价值估计学准，actor 只用可部署观测（本体 + 序数压力 + 历史 + 地形朝向）。这样既有高质量的训练信号，又保证部署时不依赖真机拿不到的量。

**Q：和用视觉/高度图的感知行走相比，触觉的独特价值？**
A：视觉/高度图看的是「地面几何」，但看不出软硬、也在脚接触后失去分辨力；足底压力是**接触时刻的直接测量**，能分辨部分/非对称支撑与柔顺地面（泡沫、碎石），两者互补而非替代。
